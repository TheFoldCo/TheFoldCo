# TheFoldCo — GitHub Pages website
This folder contains a multi-page static website for TheFoldCo. Copy the files to your repository root and publish with GitHub Pages (branch: main, folder: / (root)).

Files:
- index.html
- products.html
- about.html
- contact.html
- style.css
- script.js
- images/*.svg (placeholders)

Replace the placeholder SVGs in `images/` with your real product photos. Update prices and content as needed.
